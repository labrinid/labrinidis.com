This course covers practical predictive modeling techniques with a focus on real-world applications. 

Topics include:

- Data Preprocessing
- Data Clustering
- Association Rule Mining
- Recommender Systems
- Decision Trees
- Linear Regression
- Model Evaluation
- Ensemble Methods
- Bayesian Methods
- Time-Series Forecasting
- Monte Carlo Simulation

The course is part of Pitt's online [Master's of Data Science](https://www.sci.pitt.edu/MDS) program, delivered via Coursera.
